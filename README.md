# Which country were you referring to? — рефакторинг

## Що змінено

1. **Каскадне форматування HTML → CSS → JS.** Кожна сторінка тепер лише розмітка;
   стилі підключені через `<link>` у `<head>`, скрипти — через `<script src>` перед `</body>`.
2. **CSS та JS винесені у зовнішні файли** — жодного inline `<style>`/`<script>` не лишилось.
3. **Файли розкладені по папках за призначенням:**
   - `css/` — усі стилі
   - `js/` — уся логіка, включно з `js/data/`, `js/templates/`, `js/render/`
   - `img/` — усі зображення
4. **Усі назви файлів — у нижньому регістрі, kebab-case**
   (`Africa.html` → `africa.html`, `QuestionAsia.html` → `question-asia.html`, `1000012185.png` → `img/logo.png` тощо).
5. **Дані континентів і країн винесені в масив об'єктів** —
   `js/data/continents-data.js` (209 країн, 6 континентів). Відмальовка відбувається
   через два шаблони:
   - `js/templates/country-template.js` — картка однієї країни
   - `js/templates/continent-template.js` — секція континенту та картка-посилання на континент

   Ці шаблони використовують три рендер-скрипти:
   - `js/render/continent-page.js` — сторінки одного континенту (africa.html, asia.html…)
   - `js/render/world-page.js` — world.html (усі континенти одразу)
   - `js/render/home-continents.js` — картки континентів на index.html

## Що НЕ переписувалось (свідомо, поза межами запиту)

- Внутрішня логіка квізів (`question-*.js`), панорам (`panorama-europe.js`),
  досягнень і статистики — лише винесена з inline у зовнішні файли, без зміни поведінки.
- Два биті посилання, які були биті ще в оригіналі: `question-menu.html` веде на
  неіснуючі `question-africa.html` і `question-world.html` (ці ігрові режими просто
  ще не реалізовані в проєкті).
- Відео у `360-tutorial.html` та `question-tutorial.html` — файли `.mp4` були відсутні
  в репозиторії ще до рефакторингу.
